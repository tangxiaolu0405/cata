Cata Gateway

配置接入渠道，生成 gateway.json。页面可本地打开，无需服务器；导出后放入 ~/.cata/。

发行与工作区

base 版可自动拉起本机 cata；channel 版只做渠道适配。

渠道

可同时启用多个渠道；关闭的渠道不会写入密钥字段（或写为空）。

Telegram 已支持 长轮询 · 无需公网回调
QQ 开放平台 WebSocket 试验 无需公网回调；官方可能已停 WS

试验：本机 WebSocket 长连接（与 Telegram 类似，无需公网）。若官方已对账号关闭 WS，则无法接入 QQ。

预览与导出

下载到本机后，复制为 ~/.cata/gateway.json。

修改会自动保存在浏览器 localStorage。密钥只存在本机浏览器，不会上传。
使用：cata-gateway init 或本页导出 → 填入密钥 → cata-gateway。详见 docs/gateway.md。
